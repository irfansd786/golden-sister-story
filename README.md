# Birthday Sister Story

A personalized interactive birthday website created as a special digital surprise.

## Features

- **Interactive Birthday Cake**: Blow out candles with animations and sound effects.
- **Story Timeline**: Journey through special shared memories and milestones.
- **Memory Gallery & Photo Wall**: Showcase cherished photos and special moments.
- **Interactive Birthday Game**: Fun balloon popping game with celebrations.
- **Mystery Gift Boxes**: Interactive surprise unboxing experience.
- **Background Music**: Ambient musical accompaniment with toggle controls.

## Development

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [bun](https://bun.sh/) or `npm`

### Getting Started

1. Install dependencies:

   ```bash
   bun install
   # or
   npm install
   ```

2. Start the development server:

   ```bash
   bun run dev
   # or
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:8080` or the port shown in your terminal.

### Production Build

To create a production build:

```bash
bun run build
# or
npm run build
```
